발자국 모양 폴더
================

여기에 PNG를 넣으면 설정 창의 [모양 고르기]에 파일 이름으로 나타납니다.
[폴더 다시 읽기]를 누르면 게임을 껐다 켜지 않아도 반영됩니다.

내 것만 쓰고 배포에는 넣고 싶지 않은 그림은 사용자 데이터 폴더에 넣으세요.
모드를 다시 설치해도 지워지지 않습니다.

  %USERPROFILE%\AppData\LocalLow\TeamSoda\Duckov\DuckTracks\track_textures

권장 사양
---------
- 알파 채널이 있는 PNG. 256x256 정사각형이면 충분합니다.
- 밝기와 알파에 같은 값을 넣으세요. 발광(가산) 합성에서는 밝기가 형상을 내고
  덮어쓰기(알파) 합성에서는 알파가 냅니다. 한쪽만 채우면 다른 합성에서 안 보입니다.
- 위쪽(v가 큰 쪽)이 진행 방향입니다. 발끝이 위를 향하게 그리세요.
- 한 칸짜리 그림을 넣으세요. 여러 모양을 격자로 모아 놓으면 칸을 나누는 기능이
  없어서 자국 하나에 격자가 통째로 찍힙니다.

같이 들어 있는 21개에 대하여
----------------------------
전부 절차적으로 생성된 파일입니다. 외부에서 가져온 이미지가 아니라 파이썬 코드가
수식으로 그려 낸 결과물이라, 재배포 라이선스 문제가 없습니다.

  생성 코드: tools/generate_track_textures.py
  다시 뽑기: python tools/generate_track_textures.py src/DuckTracks/assets/track_textures
