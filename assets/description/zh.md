# Duck Tracks

走过的地方会留下脚印。

## 在真正落地的瞬间压印

每帧读取脚部骨骼的高度，只在脚**着地的瞬间**压印。不是按固定距离铺设，所以永远不会和步伐脱节——站着不动不会留下，奔跑时脚印会拉开，左右也会正确交替。

形状默认使用**你当前穿着的那只脚**。换鞋后脚印也会随之改变。

## 随心搭配

可以更换脚印的形状。从内置的 21 种中选择，放入 PNG，自己绘制，或随机抽取。

颜色也任你挑选。可以让脚印闪烁、让颜色不断变化，或做成在暗处发亮的夜光效果。

落脚时可以溅起颗粒，留下的脚印也会持续飘出颗粒。

大小和持续时间同样可调，也可以让脚印永久保留。

## 其他
