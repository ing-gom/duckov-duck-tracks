# Duck Tracks

走過的地方會留下腳印。

## 在真正落地的瞬間壓印

每幀讀取腳部骨骼的高度，只在腳**著地的瞬間**壓印。不是按固定距離鋪設，所以永遠不會和步伐脫節——站著不動不會留下，奔跑時腳印會拉開，左右也會正確交替。

形狀預設使用**你目前穿著的那隻腳**。換鞋後腳印也會隨之改變。

## 隨心搭配

可以更換腳印的形狀。從內建的 21 種中選擇，放入 PNG，自己繪製，或隨機抽取。

顏色也任你挑選。可以讓腳印閃爍、讓顏色不斷變化，或做成在暗處發亮的夜光效果。

落腳時可以濺起顆粒，留下的腳印也會持續飄出顆粒。

大小和持續時間同樣可調，也可以讓腳印永久保留。
